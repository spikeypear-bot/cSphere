# Test cases: ECL-C7 (coordinators limited to their assigned work)

Owner: Jillian · Story on **Sprint Backlog 3** · Test-case lane `ECL-C7-TC1…TC4` on **Test Cases - Sprint 3**.

The repository copy of the Sheet entries, in the IS212 Week 4 template, plus every acceptance criterion traced to the automated tests that check it. The cases came from Week 4's five steps:
1. The workflow: assign → work → reassign.
2. Happy path: the assigned coordinator works normally.
3. Cross-cutting: every endpoint, page, URL and API call.
4. Negative: other coordinators, unassigned requests, the Lead acting as a coordinator.
5. Boundary and conflict: reassignment mid-action, finished events, totals.

Test names start with the AC they check (e.g. `ECL-C7 AC14, AC15 (conflict): …`). Layers are as in `docs/testing-strategy.md`.

**Execution record:** all four cases were last executed on 17 Oct 2026 on branch `feature/eclc7-coordinator_access_scoping`, status **Pass**, automated in CI.
