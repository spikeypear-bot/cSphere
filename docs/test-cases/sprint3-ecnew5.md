# Test cases: EC-NEW5 (chronological change log)

Owner: Jillian · Story on **Sprint Backlog 3** · Test-case lane `EC-NEW5-TC1…TC4` on **Test Cases - Sprint 3**.

This is the repository copy of the Sheet entries, in the IS212 Week 4 template, plus every acceptance criterion traced to the automated tests that check it.

The cases came from Week 4's five steps:
1. The workflow: request → event → venue and equipment → safety → confirmed → completed.
2. Happy path: each kind of change is logged.
3. Cross-cutting: every role's view.
4. Negative: editing, deleting, other coordinators.
5. Boundary and conflict: no changes, legacy requests, notation-only differences, reassignment, load failure.

Test names start with the AC they check (e.g. `EC-NEW5 AC26 (negative): …`).

**Execution record:** all four cases were last executed on 17 Oct 2026 on branch `feature/ecnew5-change_log`, status **Pass**, automated in CI.
